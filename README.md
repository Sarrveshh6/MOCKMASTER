# MOCKMASTER 

Intelligent Mock Test Generator from PDF Documents

## Stack
- React.js (Vite)
- Node.js & Express.js
- MongoDB
- OpenAI API

## Getting Started

1. Clone the repository
2. Run `npm install` in the root (for server dependencies)
3. Run `cd client && npm install` (for client dependencies)
4. Set up `.env` based on `.env.example`
5. Run `node server.js` from the root
6. Run `npm run dev` from `/client`
